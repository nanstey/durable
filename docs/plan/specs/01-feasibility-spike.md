## Risk controls
- Use copies of credentials; delete temp dirs after. Redact every token in the evidence file. Do not paste credential file contents.
- Do not install anything into `~/.pi/agent`. The Android checklist runs only on the user's device in Termux, with throwaway tokens and a throwaway repo; never store real profile files on shared storage.
- Stop and ask the user if an OAuth refresh could rotate a token shared with a live session.
- Anthropic shaping tests send real requests with the operator's subscription: confirm with the user before running them.
- Tailscale and passkey tests use throwaway tags/nodes where possible and never change the operator's production ACL without asking. No Funnel. Do not register a passkey on a production origin; use a throwaway host name.

## Out of scope
Any repo source change; building the daemon; macOS/launchd (out of scope for the first fleet).

## Done when

The revision 7 addendum completes separately, per "Addendum done when" above.
