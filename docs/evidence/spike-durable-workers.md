# Slice 1 addendum: durable workers

- Date: 2026-10-23. Spec: [01-feasibility-spike](../plan/specs/01-feasibility-spike.md).
- Method: throwaway probes ran from a temporary dependency install outside the checkout. Scripts retained under [`spike/`](../../spike/) contain no credentials or machine identifiers. Results below redact runtime handles and paths.
- Honesty rule: **executed** means this addendum ran the stated probe; **documented (not executed)** means the result is from package/CLI documentation or prior evidence and is not a substitute for a run; **pending operator** needs an interactive UI or real profile decision.

## Decision

**No-go for spec 06c and spec 03 items 6a/13b at this checkpoint.** Required executed-go evidence is absent for cancellation (2), child crash recovery (3), concurrency measurements (4), child auth (8), tree enumeration (9), and the full process-containment matrix (10). The viewer and hardening findings are non-blocking: use the command-string viewer fallback, keep the skill allowlist empty, retain transcripts, and defer bubblewrap deployment.

## Executed command evidence

- Orca 1.4.237 runtime was reachable. The viewer probe’s screen read reported `source: screen`; text injection produced `received:viewer-input`; close reported `ptyKilled: true`; unrelated background work remained alive.
- `bwrap --version` reported 0.12.0. The hardening probe printed `bwrap-worktree-rw-home-tmpfs` and `scope-kill-issued=true`.
- No credentials, profile files, tokens, host names, or operator identifiers were used by these addendum probes.
