# Slice 1 evidence: feasibility spike

- Date: 2026-10-22/23 (one Linux workstation on the operator's tailnet). Spec: [01-feasibility-spike](../plan/specs/01-feasibility-spike.md).
- Scripts: throwaway, redacted, under [`spike/`](../../spike/) (excluded from the npm package by `files` in `package.json`). Everything touching credentials ran in `mktemp -d` dirs outside the checkout, on **copies**, and the dirs were deleted afterwards.
- Redaction: host names, tailnet names/IPs, logins, emails, home paths and token bodies are replaced by `<console-host>`, `<tailnet-ip>`, `<operator-login>`, `~`, `<redacted>`.
- Honesty rule: every row says **executed**, **documented (not executed)** or **pending operator**. Nothing marked executed was inferred.

## Summary

The core is a **go**:
- **pi-durable 1.4.0 works on Node 26 with `node:sqlite`.** It survives `kill -9` mid-tool and finishes the turn after restart.
- **Generic provider reuse through one profile file works.** Executed through a pi-durable Harness with credentials read only from (copies of) profile files: OpenAI-Codex OAuth, OpenRouter OAuth-form, and an `api_key` credential (OpenRouter key in API-key form), via both `createModels` and the public `ModelRuntime.create({ authPath })`.
- **Workers on a derived `PI_CODING_AGENT_DIR` work.** Profile isolation holds, `pi --continue` resumes, and the session JSONL is tail-able.
- **Orca's CLI supports steering.** Create/list/read/send-input/interrupt all have `--json`, and input injection was executed.
- **Desktop WebAuthn verification and the PWA/VAPID mechanics work.**

Four findings change the plan:
1. **`AuthStorage` is no longer a public export of `@earendil-works/pi-coding-agent`.** It was removed in 0.80.8. The public replacement is `ModelRuntime.create({ authPath | credentials })` (implements pi-ai `Models`) or our own pi-ai `CredentialStore`. D2 and the slice 2 `identity/modelAuth.ts` seam must change.
2. **A file-symlinked `auth.json` loses updates under concurrency.** The lock is `<path as given>.lock` (`realpath: false`). Directory symlinks are safe. The `default` profile must not be wired as an `auth.json` file symlink (D3).
3. **pi-auth-profiles' `defaultProfile` is not applied to `pi -p` without `--provider/--model`.** Startup model resolution runs before the extension rebinds credentials at `session_start`. Workers must pass `--provider/--model` explicitly (or `set_model` in RPC mode).
4. **Tailscale Serve and HTTPS certificates are not enabled on this tailnet.** The Serve identity-header, certificate and tagged-source checks are blocked until the operator enables them. Slices 11/12 depend on this.

Anthropic subscription OAuth: option 1 (host the transport) is **proven up to the wire, without contacting Anthropic**. A pi-durable Harness emits the shaped request (billing header block) through a provider override. The live request was **not run: it needs operator consent**. Recommendation below.
